In the dataset's original test split (test_orig), 100% of test resumes were already seen in training. Skilltrx replaces it with a strict dual-axis leakage-free protocol:

End-to-End PyTorch Bi-Encoder Architecture (BiEncoderMatcher(nn.Module))

        

          

            
Step 1 · Chunking

            
Overlapping Windows

            
254 content tokens + [CLS]/[SEP] = 256 tokens, stride 192 (64-token overlap), up to 6 evenly spaced windows per document.

          

          

            
Step 2 · Shared SBERT

            
all-MiniLM-L6-v2

            
6 Transformer layers (384-d). Unique documents in a 32-pair batch are encoded once and indexed via r_idx, j_idx.

          

          

            
Step 3 · Pool & Norm

            
Scatter-Add Pooling

            
Attention-masked mean pooling per window → index_add_ across document windows → L2 normalization (u, v ∈ ℝ³⁸⁴).

          

          

            
Step 4 · Interaction

            
769-D Feature Fusion

            
z = [cos(u,v); |u−v|; u⊙v] combining scalar cosine (1-d), absolute difference (384-d), and Hadamard product (384-d).

          

          

            
Step 5 · MLP & Loss

            
769 → 256 → 3

            
Linear(769,256) → GELU → Dropout(0.1) → Linear(256,3). Trained with class weights [0.44, 1.97, 4.55] & two-speed AdamW.
